## 2. Hard Safety Invariants (Do Not Regress)

1. **`DEFAULT_CONFIG` opt-ins stay `false`**: `autoAllow: false`, `autoAuthorizeTakeover: false`, `startImmediately: false`, `waitForIdle: false`.
2. **No blind replay of unknown submissions**: only pre-dispatch failures may retry; uncertain or attempted commits still pause cleanly (`background-v2-tests.mjs:3422` expects `interruptedTarget` confirmed-send pauses to keep `diagnostic?.code === undefined`).
3. **CAPTCHA safety boundary**: real CAPTCHA widgets/iframes (`reCAPTCHA`, `hCaptcha`, `Cloudflare Turnstile`, `verify you are human`) always pause (`captcha-required`).
4. **Consecutive takeover cap**: `consecutiveTakeoverReplies` caps at 3 consecutive replies per uninterrupted sequence (`resets to 0` on normal `sent` or explicit `RESUME`).
5. **Privacy & Storage Test Contracts**:
   - Prompts, queues, custom `takeoverReply`, URLs, and raw DOM text never enter `logs`, `incidentLogs`, `deliveryDiagnostics`, `incidentDeliveries`, or `buildActivityExport`.
   - `logEvent` reads/writes exact `'logs'` key (`writerHarness` & `background-v2-tests.mjs`), skipping `incidentLogs`/`activityStats` on `timing-diagnostics` (`controlState()` invariant).
   - `PRIVACY.md` & `docs/STORE-LISTING.en.md` stay synchronized with Schema 5 fields (`tests/public-documentation-tests.mjs`), and relative links in ZIP-checked docs must exist inside their ZIP allowlists.

## 3. Architectural Next Roadmap Toward True Zero-Interruption

1. **Eliminate Remaining Browser Fragilities**:
   - Inspect real-world `v3.4.0` exports (`incidents.logs`, `summary.pauseByCode`, `evidence`, `surface`) to pinpoint the exact trigger of any residual `paused` / `oauth-required` events.
   - Add per-provider **Connector & Account Pre-Warm Health Check** on task start (verify active GitHub / Google / Vercel connectors + Dot browser control before overnight runs).
   - Add configurable per-session **Takeover Escalation Policy** / **Soft Cooldown** (distinguish repeated identical turn loops from productive multi-step progress across different domains/actions without tripping the hardcoded 3-reply loop blindly).
2. **Shift Execution from Fragile Browser UI Clicking to Native Official OpenAI Tunnel + SSH Control Layer**:
   - The ChatGPT/Dot web UI will always impose platform-level limits (OAuth dialogs, external account redirects, rate limits, session expirations). The long-term solution is moving compute/git/deploy/verification execution behind **Windows Direct OpenAI MCP Tunnel (`openai/tunnel-client`) + Desktop Commander + SSH preflight (`native/bootstrap/ssh-preflight.mjs`)** managed directly from `setup.html` / `devices.html`, reducing reliance on Dot's embedded web browser for CLI, git, build, and deployment steps.
3. **Extension Store & GitHub Release Cadence**:
   - Ship every verified release tag (`vMAJOR.MINOR.PATCH`) via GitHub Releases with full test/packaging receipts; sync `STORE-LISTING.en.md` and submit Store updates asynchronously.
