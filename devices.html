Optional native bridge

Installation guide

Run the setup command from a verified, extracted Windows bundle. No Agent Continue EXE/MSI installer or administrator elevation is required. Only browser-managed mode registers the local bridge.

Standalone mode and temporary local pairing do not need native messaging. For browser-managed mode, register the local bridge before granting this permission.

  1. Windows command setup and local controls
    Use the guided PowerShell or CMD setup. After setup, you can open controls with a temporary local address and pairing code.
  2. Connect ChatGPT or Dot
    Follow the hosted connection steps to configure tools and authorize the chosen conversation separately. Local setup or pairing does not grant chat access.

Chat and device boundaries

Dot and ordinary ChatGPT chats have the same device-control boundary. Device actions are separate from prompt scheduling: they do not start, pause, or change scheduled jobs or change chat grants.

Tool availability and approval remain with each chat platform. Receipts here reflect only bounded state reported by the bridge, not successful remote access or tool authorization. Remote management wiring is an unreleased source candidate without real SSH or login-recovery acceptance.

Pause administrator connection

If a new request is sent, a local Windows authorization prompt follows confirmation. This affects only the administrator MCP and does not change the standard connection or prompt schedules.

If a previous Pause is unresolved, no new request is sent. Check the receipt for the previous operation.
