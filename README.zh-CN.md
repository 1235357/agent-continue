# Agent Continue

[English](README.md) | 简体中文

向一个已有的 ChatGPT 或 Your dot 会话定时发送自定义提示词。Windows 版本还提供需单独安装、明确授权的文件、Shell 与进程工具。

## Windows 设备设置（3.0.1）

选择当前账户或管理员范围，明确同意访问后，从已核验、解压的源码安装包复制并运行 PowerShell 或 CMD 命令；复制不等于执行。没有兼容 Node.js 时，引导命令可在同意后下载、校验并解压官方便携 Node。当前交付采用命令式安装，不使用已退役的自制 Agent Continue 启动器或 EXE/MSI 安装路线；Node.js、OpenAI 官方隧道客户端及上游依赖仍在浏览器外执行。详见公开仓库中的[安装命令与范围选择](https://github.com/1235357/agent-continue/blob/main/native/bootstrap/README.md#windows-command-installation)。本文不证明公开 3.0.1 安装器或 npm 路径已经可用。

**连接并授权后，会话可按所选 Windows 账户权限读写文件、执行 Shell 命令、查看及管理进程，范围不限于扩展或安装目录；这不是沙箱。** 当前账户模式使用既有权限；管理员模式单独请求 Windows 提权（UAC），将受保护运行时放在 Program Files，并注册浏览器主机及管理员所有者计划任务。独立运行的当前账户模式不注册浏览器主机；浏览器管理的当前账户模式使用 HKCU，管理员注册使用受保护的 HKLM。可选 `nativeMessaging`、Windows 批准与 OpenAI 会话授权相互独立。安装不等于会话授权。浏览器管理的安装器本身以暂停状态完成；用户本次明确同意安装及连接后，保持有效的原设置页可在核对匹配安装回执后另请求一次连接。当前账户使用独立的一次性证明，不借用管理员通道或旧的仅安装同意；已有安装不会被自动接管或解除暂停，结果不明时保留原操作 ID 查询，不盲目重发。独立当前账户安装可在提供隧道参数且同意连接时请求一次连接，引导提示要求输入 `CONNECT`；浏览器管理的当前账户引导则确认 `REGISTER`，该安装步骤不启动隧道。安装和连接可能分别需要 UAC，不承诺一次批准完成全部步骤。本候选流程仍待最终安装制品的实际验收。

托管工具需要配置 OpenAI 工作区／应用、官方隧道及受本机保护的运行密钥文件。只在本机终端输入文件路径，不要把密钥粘贴到扩展、剪贴板、复制命令或聊天。当前账户配置引用原文件；管理员绑定将密钥复制到本机受保护的 `<bundle-root>.secrets/runtime.key`，原文件仍由你管理。工具参数及敏感结果（文件正文、路径、命令输出、进程信息）经 OpenAI 传输，不经过开发者中继。访问控制不代表磁盘或内存中不存在明文密钥，也不代表工具数据不会离开设备。

固定版本的 Desktop Commander 依赖包含上游遥测，独立使用时默认开启；本项目封装在导入前同时设置 `telemetryEnabled: false` 和 `DESKTOP_COMMANDER_DISABLE_TELEMETRY=1`，启动时校验策略，安装依赖时禁用 npm 生命周期脚本。这不证明所有设备网络流量均被阻止。本机工具历史可能保留参数和结果；警告级隧道日志、按需预备的命令文件及持久控制记录与扩展精简诊断是不同存储。部分操作证据在“清空数据”后保留。启用前请阅读[完整 Windows 数据说明（英文）](PRIVACY.md#optional-windows-access-and-approvals)。

设备暂停与调度暂停相互独立；普通“断开并暂停”不停止独立的管理员运行时。管理员 Pause 请求停止，需核对原生回执与实际状态，不能把请求确认当成已经停止。Revoke 禁止该安装未来启动；OpenAI 会话访问或运行密钥需另行撤销。管理员浏览器重开恢复默认关闭，仅明确启用后恢复仍获授权的原运行意图，不得覆盖人工 Pause/Revoke。控制不能撤回已传结果、撤销既有文件修改，也不保证终止主动分离的程序。清空扩展数据或卸载扩展不会移除 Windows 运行时、任务／主机注册、受保护凭据或工具历史；设置页卸载选项目前只生成计划，不执行清理。

Checkpoint97 已记录 r11 的真实完整应用退出、重开及运行意图恢复，未再次点击 Connect。普通 ChatGPT 与 Dot 分别返回匹配的管理员权限、文件写读和自有进程结果，并在本机独立核对；Devices Pause 与 Revoke 均有匹配的停止回执，该测试安装最终已撤销且未运行。这些有范围的测试不保证未来每次恢复，也不证明当前账户托管操作、自动接管既有安装、公开制品下载或商店审核通过。匹配发布资产及提交审核回执在[运行时验收](https://github.com/1235357/agent-continue/blob/main/docs/RUNTIME-ACCEPTANCE.md)中单独记录。操作前需读取当前状态；本文不重连或重放操作。[交接记录](https://github.com/1235357/agent-continue/blob/main/docs/DEVELOPMENT-HANDOFF.md)保留日期与验证范围。

## 调度版安装

使用上方商店链接，或从 GitHub Releases 选择实际可用的安装 ZIP。解压到长期保留的目录，打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的 `AgentContinue` 文件夹，不要选择 ZIP 或上级目录。

清单声明最低 Chromium 120，不代表所有浏览器和平台组合都已测试。GitHub 自动生成的源码压缩包不是准备好的安装包，PDF 资源需要按 [开发说明](CONTRIBUTING.md) 组装。验证范围见 [VALIDATION.md](VALIDATION.md)。

## 开始任务

1. 在 `chatgpt.com` 打开已有的 ChatGPT 或 Your dot 会话，登录并等待输入框加载。
2. 打开扩展，输入提示词或导入本机文件。
3. 选择目标标签并检查设置。默认每 20 分钟重复同一条提示词，不限制已确认发送次数，到期尝试打断正在生成的回复。
4. 先运行只读页面自检，再绑定目标并开始。默认等待完整间隔才首次发送，也可开启立即首次发送。
5. 在扩展内或通过 `Ctrl+Shift+Y` 暂停。“立即发送一次”会真实提交消息，不是模拟测试。

界面默认英语，可在“设置 → Language / 语言”切换简体中文，选择保存在本机。切换不会翻译提示词、导入正文或自定义名称。继续任务沿用原提示词、目标、间隔及计数；修改配置后需重新绑定并开始，计数随新任务重置。仅导入文件不会启动或发送。

## 调度功能

| 类别 | 行为 |
| --- | --- |
| 目标 | 同时运行一个任务，绑定 ChatGPT 或 Your dot 会话 |
| 提示词 | 单条重复、队列循环、队列单遍、本地模板 |
| 计时 | 1–10080 分钟；间隔或回复结束后计时；可选本地时间静默时段 |
| 控制 | 开始、暂停、继续、立即发送、只读自检；可选已确认次数上限及停止标记 |
| 页面检查 | 目标身份、草稿和已识别附件检查；可选择等待空闲 |
| 后台操作 | 不激活目标标签，不使用系统剪贴板 |
| 界面 | 中英切换、浅色／深色／随系统主题；正文默认隐藏 |
| 记录 | 最多 200 条带本地时间戳的运行日志；诊断 JSON 导出默认使用相对时间，不包含已存储的自由文本消息 |
| 支持 | 开发者联系方式、已安装版本及 schema 4 诊断；精确时间导出仅限在支持页面明确勾选 |
| 恢复 | 仅在唯一识别到原目标后恢复；不会自动打开缺失的目标页面 |

## 单次提交与限制

每次尝试都需通过当前后台许可，且只使用一种提交机制。自动模式下，Your dot 使用 Ctrl+Enter；普通 ChatGPT 优先使用找到的发送按钮，否则使用 Enter。明确开启“扩展优先”后，自动模式优先使用目标输入区域内可用的发送按钮。也可明确指定仅按钮或仅 Ctrl+Enter。同一次尝试不会再切换其他机制。

默认保留已有草稿。如需让配置提示词替换未发送文字，请先暂停，在设置中开启 **Extension priority: allow replacing unsent text**，再开始新任务。“继续”沿用原任务配置。该模式不会提交已有附件，也不会绕过暂停和目标检查。详见 [扩展优先说明](docs/COMPOSER-PRIORITY.md)。

只有匹配的新用户消息标记才计为确认；输入框清空或忙碌状态不等于成功。无法确认时保留“结果未知”，不增加已确认次数，不立即重试，完整正常间隔后才可能再次尝试。先前消息仍可能已经送达，因此不保证恰好一次交付；遇到未知结果应暂停并核对会话。暂停无法撤回已经发出的提交动作。

确认只是页面层观察，不是服务端回执。旧节点被复用为新消息时仍保留未知；旧历史同时换成新节点与此前未见的 ID 时，仅靠这些 DOM 检查无法可靠区分它与真正的新确认。

电脑和浏览器必须运行，目标页面必须可执行且已登录。定时器、后台连接与防丢弃设置不保证精确时刻，也无法阻止所有冻结。错过的周期不会集中补发。可选 `power` 权限仅防止空闲休眠，不覆盖手动休眠或合盖行为。网页改版可能导致不兼容；扩展不增加账号额度或上下文，也不保证 Agent 持续工作或完成目标。

## 文件导入

文本、Markdown、结构化文本、HTML、DOCX 和可提取文字的 PDF 在本机处理。HTML 不执行脚本；DOCX、PDF 提取文字而非保留排版。PDF.js 资源随包提供，不调用在线转换或运行时 CDN。不支持旧 `.doc`、加密文档、密码保护 PDF；扫描 PDF 需另行 OCR。

单文件最多 5 MiB，单条提示词最多 100,000 字符，队列最多 50 项、合计 600,000 字符；DOCX 正文 XML 最多 4 MiB，PDF 最多 100 页。编码识别及阅读顺序可能有误，敏感或依赖排版的文档需检查提取结果。详见 [文件格式](docs/FILE_FORMATS.md)。

## 数据与权限

提示词调度／文件导入无需独立扩展账号或 API key，不使用开发者收集服务器、分析遥测或云同步；仍需在目标网站登录 ChatGPT，已发送提示词按该服务政策处理。可选 Windows 托管工具则需要本机运行密钥及上述独立授权，并经 OpenAI 传输工具参数／结果，不能套用调度版的“无需密钥”说明。遥测配置与 Windows 记录详见[隐私说明](PRIVACY.md#windows-telemetry-logs-and-durable-records)。

`https://chatgpt.com/*` 用于目标识别、检查、填写、发送及恢复；`activeTab` 用于用户操作时访问所选标签；`scripting` 执行页面逻辑；`storage` 本地保存配置、正文、队列、模板、语言、主题、日志及恢复状态；`alarms` 唤醒调度；可选 `power` 在明确开启时防止空闲休眠。

历史稳定版 v2.2.1 不请求 `nativeMessaging` 或包含 Windows 控制；3.0.1 候选增加可选 `nativeMessaging`，用于与单独安装、绑定扩展的本机桥接交换有限状态、连接、Pause/Revoke、恢复及预备进程引用检查。它不安装软件、不授予 Windows 提权或会话访问，也不通过桥接发送任意 Shell 正文。未增加全站点、Cookie、剪贴板或 debugger 权限；设置页可在用户操作后用剪贴板 API 复制命令，调度发送不使用剪贴板。这些浏览器权限边界不限制已单独授权的 Windows 账户级工具。

本地存储不加密，隐藏正文不等于安全隔离。默认配置导出不包含提示词及队列正文，需明确选择才包含。“清空数据”保留语言及持久设备／控制证据，移除管理员浏览器恢复偏好，但不请求 Windows Pause/Revoke，也不删除原生状态、原始文件、导出文件或已发送数据。完整数据流和删除范围见 [隐私说明（英文）](PRIVACY.md)。
